# 机械精模工坊 · Mech Lab

用 three.js 把动物做成 20 秒的 3D 机械结构动画：扫描成型 → 分体拆解 → 环绕检视 → 磁吸归位 → 运行演示。纯静态网页，无需构建、无需服务器端。

## 内容

- 10 只手工设计的机械动物：边牧、虎鲸、章鱼、天鹅、猎豹、赤狐、变色龙、雕鸮、战马、葵花鹦鹉
- 每只动物有专属的拆解方式（径向爆散、波浪剥离、花开式、羽毛飘散、漩涡、工程爆炸图、舱门开合、剥洋葱、扇形、变色波）
- 电脑端和手机端自适应；手机支持单指旋转、双指缩放
- 上传任意图片可生成零件化草图（仅预览）

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 全部页面、模型和动画代码（参考图片已内嵌） |
| `three.min.js` | three.js r128 |
| `.nojekyll` | 让 GitHub Pages 原样发布 |

## 部署到 GitHub Pages

1. 新建仓库，把本文件夹里的全部文件（包括 `.nojekyll`）上传到仓库根目录
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存
3. 一两分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`

本地预览：直接双击 `index.html`，或在该目录运行 `python3 -m http.server` 后打开 `http://localhost:8000`。

## 操作

- 拖拽旋转 · 滚轮 / 双指缩放 · 双击复位 · 空格暂停
- 底部时间轴可拖动到任意阶段；「标注」开关零件标注
